# 麦粒的四足动作

## 关键点和控制

保留 CC BY 4.0 德牧模型，把模型已有的骨骼当作三维关键点，再在头骨下增加叼取用的吻部锚点。StanfordExtra 的犬类图像标注可帮助核对四肢、耳、尾巴和脸的名称。游戏里已经知道这些点的三维变换，可以直接读取。肩胛、脊柱、胸与骨盆来自游戏骨架，支持计算承重和俯仰。 [StanfordExtra 原论文](https://arxiv.org/abs/2007.11110) · [原始关键点定义](https://raw.githubusercontent.com/benjiebob/StanfordExtra/master/keypoint_definitions.csv)

| 部位 | 对应骨骼 |
| --- | --- |
| 左右前腿 | 肩胛 `DEF-scapula`、肩 `DEF-front_upper`、肘 `DEF-front_forearm`、腕 `DEF-front_paw`、趾 `DEF-front_toes` |
| 左右后腿 | 髋 `DEF-hind_thigh`、膝 `DEF-hind_shin`、跗 `DEF-hind_hock`、后爪 `DEF-hind_paw` |
| 躯干 | 骨盆、两段脊柱、胸、两段颈骨 |
| 头与尾 | 头、两耳骨、四段尾骨、吻部叼取锚点 |

桌面「设置 → 显示骨骼关键点」可查看左右肢、吻部以及爪子的接地状态。左右用不同色的线表示，绿色爪点表示支撑，琥珀色表示抬脚或者动作中的抬爪。

## 四拍走路与动作姿态

犬类慢走研究观察到一侧后肢先着地，紧接同侧前肢，再换到另一侧。以左后开头就是左后、左前、右后、右前。使用研究的约 58% 支撑周期做初始参数，步幅和转弯仍按游戏里的德牧骨架调校。脚落下时保留一个世界坐标，抬起的脚沿弧线走向下一个落点。逆运动学调整关节旋转，使骨链够到落点。前进、转弯改变步伐，原地动画不需要整体滑向目标。 [犬类步态实测](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0133936)

坐下时应保持前爪支撑、后躯下沉。抬爪时先给支撑腿留出重心空间；作揖压低前身，保留较高的后躯；叼物用吻部锚点检验距离并带着道具一起移动。动作由 Unity 骨架执行，语音或 Agent 仍从已有动作里选。 [Penn Vet 坐姿与伏卧动作参考](https://www.frontiersin.org/journals/veterinary-science/articles/10.3389/fvets.2020.00470/full)

这版使用程序化动画，着重处理平地步态和近距离互动。3DDogs 提供了实测的步行与小跑数据，可作为研究参照，原数据限非商业研究用途，本项目的体验包不包含它。 [3DDogs 数据和许可](https://cvssp.org/data/3DDogs/)

## Unity 验证

`DogMotionValidation.Run` 在公寓中让麦粒沿直线走约 4.19 米，再检查坐下、抬右爪、作揖、趴下和叼取。四爪按顺序交替落下，测试直线路段中爪点相对该次落地位置的最大水平偏移约 11 厘米。落点固定，但真实骨链仍受转动范围和可达距离限制。坐下时前爪保持接地，作揖时胸部低于骨盆，叼取时道具随吻部锚点移动，测试覆盖的四肢和脊柱骨段长度保持一致。头显实物和复杂地面还需单独验收。
