# 城市里有一只狗 · 麦粒的第一周

## 开始游戏

- Windows 解压体验包后运行 `CityDog.exe`。把同目录下的数据文件夹、Unity DLL 和模型署名放在一起。
- Unity 源工程用 **2022.3.62f3** 打开，在 `Assets/Scenes/Dog1.unity` 点 Play。进主菜单后点「回家见麦粒」。
- 左键操作面板。按住右键环顾并用 WASD 移动。Esc 在普通游戏状态下打开暂停菜单。
- 进度自动存档。游戏关闭后需求不下降，每个本地日首次回家奖励 3 枚小骨头。

## 一晚体验

1. 照护页喂食、换水、陪它玩，完成第一章。此时可用 8 枚小骨头在地图解锁街区公园。
2. 在公园点「遛弯」，带麦粒走到绿色路标。结束后点「清理便便」。到「互动」练口令，成功后表扬。五章的目标列在右上角。
3. 点「晚安」教学按钮或输入「晚安：坐下、抬右爪、拜一拜」。表扬后记入存档，下次只输入「晚安」就能调用。用「我心情不好：叼球、坐下」可教一个两步情境约定。
4. 想体验原版的陪伴约定时，点「教它：心情不好时叼棒棒糖」，等麦粒把道具带回来再表扬。重开后说「我心情不好」可取回道具。如果另外教过同名的动作串，动作串会优先触发。
5. 休息、照护和继续训练可提升等级。4 级用 28 枚小骨头解锁露台小屋。第五章结束后仍可回到三个地点继续生活。

首次口令会犹豫，重复同一个口令就能开始试练。麦粒空闲时可能主动叼球、邀玩或休息，拜一拜完成后的表扬窗口可以强化动作。去「设置」可显示骨骼关键点、关闭奖励提示音或清除口令记忆。照护手记会提示真实养犬涉及的日程、开支和备用照护。

## 模型与动作

Dog1 默认启用大模型。已有有效配置时，游戏会按需发送当前文字和相关训练或场景信息。「设置」显示配置状态，可填写兼容的 Chat Completions 地址、模型名和本次运行的 Key。本地 Ollama 地址为 `http://127.0.0.1:11434/v1/chat/completions`。训练页通过模型匹配技能，再由本机语音服务均匀抽取 1–100，抽样值小于或等于当前技能成功率时尝试执行。训练调试记录可查看模型回复、抽样值和实际执行结果。场景回应在模型不可用时可由本地规则处理。

在头显里，把手柄伸到球、食盆或水盆旁，按住扳机拿起。松开时可放下或抛出球，食水盆会直立落下。说「把玩具拿过来」时，麦粒会找球现在的位置。说「去吃饭」或「去喝水」时，它会找相应的碗，碗需要放稳且有食物或水。饱腹度或饮水度高于 40 时，麦粒会婉拒对应的口令。

## 构建和来源

可在 Unity 批处理调用 `Dog1DemoValidation.BuildWindows` 输出到 `Builds/CityDogDemo`。项目也带有 `Dog1DemoValidation.Run` 和 `DogLifeValidation.Run` 两个 Play 验证入口，后一项需要给 `KEEP_A_DOG_TEST_SAVES` 指定空测试目录。原德牧骨架和贴图采用 CC BY 4.0，见 `ThirdParty/ATTRIBUTION.md`。概念图是场景设计参考，游戏内的公寓、公园与露台由 Unity 几何、灯光和道具实现。

策划、来源与后续制作任务见项目根目录 `CITY-DOG-ROADMAP.md`。
