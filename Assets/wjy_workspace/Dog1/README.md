# Dog1 · 麦粒的第一周 5.0

完整玩法、语音设置和历史研究见[项目 README](../../../README.md)，本轮范围见[5.0 发布说明](../../../docs/V5.0.md)和[VR 走查](../../../docs/qa/dog1-v5-vr-audit.md)。Dog1 是当前统一的 VR 游戏；电脑窗口用于无头显调试，Dog2 保留为历史轻量场景。

## 开始体验

用 Unity **2022.3.62f3** 打开仓库根目录，在 `Assets/Scenes/Dog1.unity` 点击 Play。Windows 构建入口为 `Dog1DemoValidation.BuildDog1PcVr`，输出 `Builds/CityDog1PCVR/CityDog1PCVR.exe`，同一程序支持 Quest Link／Air Link PCVR 和电脑窗口。保留同目录的数据、Unity 运行库、SpeechService 与署名。

VR 左摇杆移动、右摇杆分段转向，扳机射线操作空间手账，左 X 收放手账。右 A 按住说话，松开转写，B 取消。空手缓慢抚摸头侧会有反馈；近手握把或扳机可拿玩具，食水碗用扳机提起并直立放下。拿玩具使用的扳机不会同时点菜单。看向可达的门、花洒、碗或电梯设施，空手按右握把操作。

电脑左键操作面板，右键配合 WASD 移动，G 拿起／放下，V 按住说话，Esc 取消语音或暂停。进度自动保存，关闭后需求不下降，每个本地日首次回家可领取 3 枚小骨头。

## 陪伴与训练

从喂食、换水和陪玩开始，按手账完成五章照护任务，解锁公园和露台。趴一会儿、回狗屋和去软垫实际完成都算休息。麦粒主动伏身邀玩时，可以陪玩、安静陪伴或稍后；扔球后目前需要再用口令或陪玩入口让它叼回，尚未自动追取。

六项技能为坐下、趴下、抬右爪、转圈、过来和叼球。概率从 40% 开始，实际完成后 +10%，十二秒内开始的有效表扬再 +10%，最高 90%。未抽中会使用安全备选反馈；正常照护、休息和多动作计划不抽签。改做另一项活动后，旧的训练表扬窗口会失效。

自由语言交给 DeepSeek 理解，由统一 JSON 返回 `reply`、`decision` 和 `actions`；动作目录、状态和目标均由后端再次校验，不按句中关键词猜动作。最多三个待执行项目，等待最多五秒，新排队口令优先，同一句动作串顺序保留。关节、移动、拾取和奖励由游戏程序执行。[协议说明](../../../docs/DEEPSEEK-CONTROLLER.md)

设置页配置模型服务和个人 Key；Windows 按用户与接口加密保存在本机数据目录，源码不含个人凭据。语音使用本机 Whisper，逐轮文字与失败原因可在手账查看。真实 DeepSeek 的协议测试与模拟模型驱动场景的验证分别记录，实体头显仍需设备实测。

默认使用原有边牧，已有存档保留所选犬种。骨架关键点、全身动作、微动作和步态可在「动作」页预览，预览不推进任务。模型署名及许可证见 [ThirdParty/ATTRIBUTION.md](ThirdParty/ATTRIBUTION.md)。
