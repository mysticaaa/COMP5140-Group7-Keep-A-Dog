# 城市里有一只狗 · 语音与 Quest Link 试玩

## 桌面

运行 `CityDog.exe`。点「回家见麦粒」或「继续生活」。按住 V 说话后松开，或者按住底部录音按钮。识别后字幕显示本句，交给同一套 DogAgent。Esc 可取消当前录音，仍可在说话页键入。原五章照护、地点、骨头、训练与存档可继续使用。

## Quest 3 + Windows PC

1. 在 Windows 的 Meta Horizon Link 中设为活动 OpenXR Runtime，并在头显里进入 Quest Link。
2. 确认 Windows 能收到 Quest 麦克风的输入。运行 `CityDogPCVR.exe`，或在 Unity 2022.3.62f3 打开 `Assets/Scenes/Dog2.unity` 点 Play。
3. **右手 A 按住讲话、松开转写，B 取消。** 左摇杆移动，右摇杆分段转向。手柄射线扳机松开时选择手记按钮。手记可重新摆到眼前，靠近麦粒的头部缓慢移动手柄可触发抚摸回应。
4. PC 窗口 F8 开始／结束录音、F9 重新连接 OpenXR，也可键入做调试。PCVR 试玩目前是公寓里的语音、陪伴和训练，桌面版包含完整照护章节。

## 首次使用中文语音

组装好的本机项目构建会自动找到已装在项目内的语音服务。独立压缩包解压到其他位置后，首次使用需要 Windows 上的 Python 3.10–3.12。进入游戏旁边的 `SpeechService`，在 PowerShell 执行：

```powershell
.\Setup.ps1
```

第一次会下载依赖和 Whisper base 模型，之后麦克风录音只发到本机回环服务，可以离线转写。如果 Python 不在 PATH，用 `-PythonPath` 指定它。安装完成后游戏会在开始录音时启动本机服务，也可运行 `Start.ps1` 手动启动后再进游戏。音频录制基于按键，不持续监听麦克风。转写句子只有在你启用兼容的 LLM 后，必要时才随少量训练摘要发给模型接口。

## 试这几句

- 「麦粒，请你坐下，然后抬起你的右爪。」
- 「晚安：坐下、抬右爪、拜一拜。」做完后表扬，下次只说「晚安」。
- 「我心情不好的时候，给我叼来一颗棒棒糖。」做完后表扬，下次只说「我心情不好」。
- 开启兼容模型后，可以用更模糊的描述尝试请求，例如「我今天有点提不起劲，想让它陪我一会儿」。语义结果取决于所选模型，Unity 仍校验动作。

## 状态

已在 Windows 上构建桌面与 Quest Link 版本。使用本机 Whisper 对合成中文 WAV 做真实转写；用 Unity 测试转写回调、模拟模型序列、射线按钮和动作保存回放。Quest 真实麦克风、头显双眼和实体按键需连设备验证。当前体验包为 Windows PCVR，Android 一体机在下一阶段。
