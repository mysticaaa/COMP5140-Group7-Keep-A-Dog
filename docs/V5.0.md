# 5.0 · 麦粒的第一周

日期：2026-11-26。

**状态：本轮本地验收完成。** 23 个验证入口、真实 DeepSeek 六例、Windows 5.0 构建和两次启动检查通过。发布标识为仓库 `main` 与带说明的 `5.0` 标签；在线源码以该标签为准。

本版在 `douga-3.0` 的统一 AI 链路和玩家体验修复上，整合 main 的概率训练、可搬食水碗和扳机抓取，并对 Dog1 的 VR 交互再做一轮完整走查。游戏继续使用同一个 Dog1 场景与存档，支持 Windows 上的 Quest Link／Air Link PCVR，以及无头显时的电脑测试窗口。

## 本版主要内容

- **统一的 DeepSeek 控制。** 自由语音和文字连同狗的需求、场景状态、近期交流、训练记忆及动作目录发给模型。返回的自然回复与动作计划分开，后端核对动作、目标及实际可执行条件，不恢复句中关键词动作兜底。
- **有限、可检查的动作计划。** 最多三个待执行项目，等待窗口五秒；新来的排队口令优先，同一句动作串仍按指定顺序执行。过期取消尚未开始的动作，已经开始的动作先完成。
- **六项概率训练。** 坐下、趴下、抬右爪、转圈、过来、叼球从 40% 开始，实际完成后增加 10%，最高 90%；未抽中或实际受阻不计成功，使用模型选择的安全备选反馈。普通陪伴、休息和照护不抽签。
- **表扬与记忆。** 成功练习后十二秒内开始说话，可以由模型判断真诚表扬并再次强化；转写耗时不吞掉回应窗口，同一次成功只强化一次。命名动作串和未来条件约定继续通过实际演练、完成及表扬保存，近期聊天不会全部写入长期存档。
- **可搬动的食水碗。** 食盆、水盆可用扳机拿起并直立放下，狗使用搬动后的实际位置。手持、移动、过高、不可达或空碗均不能算作吃喝完成；开始与结束都会复查。模型也可选择 `eat`／`drink`，不会凭空给空碗添粮或水。
- **玩具抓取与菜单互斥。** 三个场景保留球、棒棒糖毛绒玩具及各自的小玩具。支持近手握把／扳机抓取、展示与有界投掷，抓取使用的扳机不会顺带点击手账。狗叼取的玩具不能同时被手抢走。
- **统一照护结果。** 趴一会儿、回狗屋、去软垫实际休息后都会恢复体力并记录休息；自主休息只恢复自身状态。已完成的活动仍可推进任务，奖励冷却只限制奖励；失败或取消不能领奖。
- **主动互动与动作。** 麦粒可伏身邀玩，玩家选择陪玩、安静陪伴或稍后。保留自主探索、歪头与注视、闻嗅、理毛、抖毛和抚摸时的探头摇尾，开发者动作预览独立于任务和奖励。
- **语音与连接诊断。** 保留逐轮语音记录、本机语音服务重连、Windows 加密保存密钥，以及鉴权、限流、网络和模型输出校验的明确反馈。

## 本轮走查修复

1. **多帧追踪丢失后的菜单误点。** 抓取使用的扳机在追踪丢失、暂停或恢复时继续保持输入归属；未知追踪状态不等于扳机已松开，恢复后的真实释放仍由抓取流程消费。
2. **跨活动误强化旧训练。** 开始新的照护、休息、故事回应、场景／犬种切换或动作演示等活动时，撤销上一轮训练的待表扬窗口，防止表扬本次互动却给旧技能增加成功率。
3. **跨楼层假完成。** 靠近、取物和交付增加同层判断。VR 使用玩家 Origin 的地面高度，桌面使用固定眼高换算，不把正常眼高或蹲下误当成不同楼层。分处两层时自然说明不可达，途中变层也不能把玩具算成交到玩家面前。
4. **花洒开关受视野影响。** 花洒使用独立的 `showerRunning` 状态控制水流与飞溅两组粒子，停止时同时清空残留粒子，不再用可能受视野裁剪影响的 `isEmitting` 充当开关状态。

## VR 操作

左摇杆移动，右摇杆分段转身。手柄射线用扳机按下、松开选中手账按钮；左手 X 收起或重新召回手账。右手 A 按住讲话、松开转写，B 取消。设置页可切换麦克风、重连 VR、显示骨架和当前动作，或开关奖励提示音。

近手用扳机抓玩具或食水碗，玩具也支持握把抓取；松开对应按键放下或抛出。空手在麦粒头侧缓慢移动可触发抚摸反馈。手边没有玩具可抓时，看向门、食水碗、花洒或电梯设施，按右握把互动。照料页的遛弯开始后可以取消，不会领取完成奖励。

电脑窗口保留鼠标操作手记、右键与 WASD 移动、G 拿起／放下、V 语音、Esc 取消／暂停、F8 录音切换和 F9 重连。

## 验证与范围

本轮测试结果由[完整 VR 走查记录](qa/dog1-v5-vr-audit.md)汇总。测试脚本使用隔离存档，固定语音样本、受控模型回包、实际 Unity 动作与物理过程分别验证；真实 DeepSeek 的协议联调单独记录。

本轮 **23 个 Unity 标准与专项验证入口全部通过**：20 个标准回归入口，加 V5 Journey 核心、虚拟输入探针和设施三个专项入口。这是入口数量，不是断言数量，也不代表实体头显验收。

整合场景最终复验通过 **81 项断言**；V5 Journey 核心通过 **87 项**，覆盖菜单、抚摸、追踪恢复、暂停、遛弯、搬碗、切场景、楼层可达和旧表扬隔离；虚拟输入探针通过 **4 项**；设施专项通过 **37 项**，覆盖三扇门、花洒水流与飞溅两组粒子的开关，以及暂停恢复。

本轮真实 DeepSeek 六例语义与协议联调 **6/6 通过**：明确练习坐下、普通坐下口令、真诚表扬、引用／否定表扬不强化、回屋休息不抽签，以及持碗时拒绝吃饭。真实模型输出与协议解析的结果，和模型桩驱动实际场景的结果分别记录。

## 当前边界

- 扔球后自动追取尚未接通。VR 可以抛球，落稳后通过语音、训练或陪玩入口让麦粒叼回。
- 狗尚不能自主搭电梯跨楼层找玩家；本版会阻止跨层假靠近与假交付。
- 搬动食水碗的位置在当前场景有效，尚未跨场景或跨存档保留。
- 发布范围是 Windows PCVR，未提供 Quest 独立 APK，也不把本次走查称为 Steam 上架验收。
