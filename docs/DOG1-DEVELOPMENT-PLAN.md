# 麦粒的第一周 · 3.1 后续开发计划

下一版优先把领养第一周做成可在头显里从头玩到结尾的故事。沿用 Dog1 的边牧、房间、物理道具、训练和存档。Windows 上继续用同一个试玩程序做桌面调试和 Quest Link PCVR 验证。

## 3.1 的起点

- 当前版有五章照护目标、小骨头和场景解锁。公寓、街区公园和露台小屋均可游玩。头显手账能显示章节进度，支持回应麦粒的邀玩和休息。五个剧情事件、其余支线与第七天的演出详见[第一周故事方案](DOG1-FIRST-WEEK-PROPOSAL.md)，后续再接入游戏。
- 麦粒会靠近后停步看玩家，偶尔接上邀玩，走入小屋后转身休息，也会停在可达物品旁观察。3.1 调整了甩毛、站定与动作衔接。先用现有行为表达剧情，遇到实测效果有限的动作，再决定是否增加动画。
- 本地规则可以处理照护、自主行为、训练和已保存的约定。可选 Agent 已在本机用模拟模型验证；中文转写走过固定 WAV 到游戏的链路。实体 Quest、头显麦克风和线上模型需分别实测。

## P0 · Quest 实机与交互回归

**交付。** 用同一 Windows 构建跑一次实体 Quest Link 主流程。记录头显、手柄、运行时和麦克风配置。在公寓做完整检查，再到公园和露台复查道具与场景切换。观察帧时间和图像流畅度，在陌生玩家佩戴试玩时确认手记字号、板面距离、抓放提示和重新居中是否易用。

**验收。** 从冷启动进入 VR，双眼画面、两只手柄与手账射线正常。抓取、释放、抛掷、递玩具、轻抚和操控设施可复现。切场景、暂停和重连后可继续操作。中文按住说话时能从头显麦克风录入并取消，听错时可以用手柄或文字继续。至少覆盖一组常用短句、完整口令和安静背景下的误触发检查，记录失败样本及响应时间。

**前置。** 需要可用 Quest、控制器、Windows 主机和 Link 环境。编辑器回归与剧情脚本拆解可先并行。Quest 独立安装另需 Android 构建、头显性能和本地语音方案评估，待 PCVR 流程稳定后再确定范围。

## P0 · 麦粒与道具的状态衔接

**交付。** 优先打磨玩家最常看到的走弧线、停步、歪头、邀玩、甩毛、玩具观察和进屋休息。持续记录默认边牧的脚掌支撑和停点。确认玩家手里的玩具、落地玩具、狗叼着的玩具各有清楚状态，家具保持碰撞，能拿的物件有一致反馈。

**验收。** 在三个现有场景以玩家视角复测。连续弯道与停步保持脚掌支撑，近看时步幅接近正常慢走。小屋有足够掉头空间时，麦粒能走进去、转身并面向出口休息。低优先级的下一次兴趣点和重复关注请求，等观察或邀玩结束再执行。障碍出现、目标被拿走、托管中的道具切场景时能安全结束当前行为，玩家仍能继续照护和游玩。对可见脚滑、穿模、意外中断保留短片与复现条件。

## P1 · 领养第一周剧情落地

**交付。** 先接通「到家安顿 → 公园岔路」两章，用门口、熟悉的毛绒玩具、软垫和公园停靠点引导玩家。再完成「雨天改计划 → 学会相处约定 → 第七晚收尾」。让照护从剧情中的处境自然发生。公园首次访问和露台结尾按剧情临时开放，正式解锁继续使用等级与小骨头。给现有邀玩和休息补足跳过流程，再制作公园回望和归家招呼。

**验收。** 五章以五件不同的事完成。玩家可以回应、搁置或错过麦粒的主动邀请。第七晚在公寓或露台均有收尾，周记能引用一次真实选择，错过支线也能结束第一周并进入自由生活。关掉模型、使用头显手柄可完整通关。逐章测试中途保存后恢复，已购买地点、小骨头、犬种和学会的口令能从旧存档迁移，重复加载同一事件也只结算一次。

**前置。** 策划与事件状态可先编写。头显的实物引导、雨天替代路线和终章取物演出依赖 P0 的设备、道具及动作回归结果。

## P2 · 真实语音与可选 Agent

**交付。** 先让本地规则覆盖故事和照护。用已注册的玩家、手柄和道具状态构造场景输入，将可用动作的标签、目标与前置条件交给模型选择。Unity 逐步复核距离、遮挡、体力和道具状态。短期只保留本轮对话与反馈窗口，长期写入玩家明确教过并确认的口令和约定。

**验收。** 配置获授权的线上服务后，记录中文自由表述、玩家靠近时的回应、最长三步动作链、长期约定跨重启等场景。逐一检查超时、无效动作、道具移动和中途断网，确认能回到本地回应或结束本次互动。头显实录验证清晰短句、口音、室内噪声与听错后重试。分别记录中文转写、模型选择和动作执行的耗时与结果，凭据留在本机或会话环境。

**前置。** 依赖 P0 的头显麦克风和动作状态回归，以及可用的测试账号。线上服务未准备好时，可以继续用本地录音样本及模拟模型做回归。

## P3 · Steam Demo 发布准备

**交付。** 在故事版冻结后，用干净 Windows 环境验证安装、启动、语音依赖和存档。制作实际游戏截图与预告素材，核对模型、美术、音频和语音组件的分发许可。明确商店页的 Quest Link PCVR 条件、桌面入口和语音选项。若上线版保留运行时模型生成内容，按提交时适用的 Steamworks 流程填写内容调查。

**验收。** 新玩家能从安装走到第七天结尾，旧档可继续，无模型时完整通关。对照实际设备实测结果填写支持范围和配置要求，记录帧率、掉线恢复与存档问题。确认可分发后再准备 Steam Demo 构建、商店材料和审核。相关发布参考见[项目设计路线图](../CITY-DOG-ROADMAP.md)。
